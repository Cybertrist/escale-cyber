# Contexte

Sur un chantier, les échanges avec le **maître d'ouvrage** (le client) sont constants : situations de travaux, avenants, validations, réceptions. Les montants en jeu sont élevés et les délais toujours serrés.

Les escrocs s'en servent : ils imitent le client, l'architecte ou un sous-traitant pour détourner un paiement ou obtenir des documents. Ils choisissent souvent un moment de forte pression, comme la veille d'une réception ou une fin de mois.

# Fiche réflexe

<Fiche titre="Échanges de chantier : les 3 réflexes">
1. **Pression sur un paiement ou une signature = vérification**, par téléphone, au numéro connu.
2. **Changement de RIB = contre-appel systématique**, même depuis une adresse connue.
3. **Jamais tes identifiants** pour accéder à un document.
</Fiche>
